# Kiln

The marketing site for Kiln — a fictional runtime for autonomous AI agents.
Built with Next.js 15, React 19, Tailwind CSS, GSAP-ready motion primitives
(Framer Motion + Lenis), and an original React Three Fiber hero centerpiece.

Follows the repo's house style (see `/CLAUDE.md`): full-bleed warm-dark
canvas, cream type, ember used only as editorial credit, dashed hairlines,
one filled surface per screen.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
